- **任铁樵组**：新浪博客「至真斋主新解」系列逐章转录《滴天髓》京图原文、刘基注、任批三层，本集只取标注「任铁樵批」的段落与四柱/大运，现代新解文字一律不入集。ren-005/006（寒暖对造）、ren-011/012（燥湿对造）为原书成对命例，成对保留。
- **乾隆造（ren-016 / xu-003，cross_system=true）**：同一命造两家断——任铁樵主「支全四正、两冲制伏」，徐乐吾主「喜其冲克」，侧重不同而同许其贵。生年（1711-09-25）以维基百科乾隆帝条/《清史稿》核对。此为本集跨大师同造的黄金样本。
- **徐乐吾组**：xu-001/002 为徐注自举的成对例（同为子午卯酉四冲，一成一败），非沈孝瞻原文命例，已在 life_context 注明。
- **万民英自造（sanming-001）**：四柱由其自述文字（庚寅日、十二月大寒后、丙戌时、壬午年柱）拼合，后人研究文献（《三命通会》相关考述）同载此造；其自记的丁巳运癸亥年罢官丧母、戊午运甲戌年火灾皆出自原书自述。原书全文 PDF 经 GitHub 公版镜像取得（mymmsc/books）。
- **韦千里组**：《千里命稿》PDF（fengshui86 镜像）核蒋介石造原文（含起运年龄与大运序列）；《呱呱集》PDF（luckclub 古籍典藏，含原文层）逐页核读上集名人命造，四柱与断语均按原文层录入，白话译文层不用。名人卒年/大事以通行史实核对（张作霖 1928 皇姑屯、杜月笙 1951 卒于香港、崇祯 1644 甲申、阎锡山 1960-05-23 卒等皆与韦书所记互证）。
