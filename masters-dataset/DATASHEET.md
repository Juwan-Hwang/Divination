# Datasheet — MastersDivination Benchmark v0.1
（按 Gebru et al.《Datasheets for Datasets》提纲）

## 动机（Motivation）
- 为何建：市面上不存在「大师占例」结构化验证集；「算得准不准」长期停留在自说自话。本集把验收标准外化为可复跑的基准：与大师原断的一致性。
- 谁建：本项目（用户立项，多 agent 并行收集：中方占卜/中方命理/西方/现代大师四路），种子集由知识库建设流程自公版典籍抽取。
- 资助：无外部资助。

## 构成（Composition）
- 实例：一条 = 一个真实历史占例（subject + context + 一位或多位大师的预测 + 应验）。
- v0.1：6 例（六爻 3、梅花 3），中文繁体原文，字段见 SCHEMA.md；dev 4 / test 2。
- 敏感信息：均为数百年前典籍人物，无在世个人隐私；后续现代大师卷只收其**公开发表**的预测。
- 缺失：八字/紫微/周易文本占/塔罗/占星卷 v0.1 为空（无合格可核成例），如实登记，不以二手转述填充。

## 收集过程（Collection Process）
- 来源：公版典籍全文（维基文库《增删卜易》《梅花易数》本地存档，见 ../sources/），逐字节录、未改写关键信息；每条 provenance 到书名与章节。
- 划分：基准统一按约七三随机指定 dev/test，test 金标封存（holdout/）。
- 伦理：无人类受试者招募；现代卷将只用公开出版物并逐条标许可。

## 标注/整理（Preprocessing / Labeling）
- direction 与 key_assertions 由整理者据原文断语编码（结构化方向四值）；编码规则：以大师断语的主导倾向为准，混合断（如「伤而不至凶危」）主方向记 negative 并在 key_assertions 保留减凶断语。
- 原文为繁体，保留不转简，避免转写误差；节录以 notes.tags=excerpted 标注。

## 内部版与公开版
内部版为全量（含现代版权内容），仅供内部评测；未来公开发布版将按逐条 redistributable 字段过滤导出。两者是同一数据集的两种导出，内部成绩以全量版为准。

## 推荐用途（Uses）
- 评测 AI/占卜系统与大师的一致性（主用途）；占卜教学中的成例回归测试；术数史研究的案例索引。
- 不推荐：作为「占卜有效性」的证据；作为任何现实决策（医疗/投资/法律）的依据；对 test 集反复调参（防背题）。

## 局限与偏差（Limitations & Biases）
1. **幸存者偏差（结构性）**：典籍成例是编者筛选的「验例」，未验之例不传。本集成绩只反映与大师的一致性，系统性高估「占卜灵验度」——使用者不得据此宣称预测效力。
2. **训练语料污染**：名例（如观梅占）极可能已被大模型背诵，famous 标签条目成绩须打折看待；缓解靠扩充冷门古例与封存 test 集。
3. **文本层累与托名**：梅花易数托名邵雍、《增删卜易》经编集，个别细节可能经后世润饰；disputed 标签如实标注。
4. **文化与时代偏倚**：v0.1 全为中国明清/托名宋的案例，问题类型偏官职、文书、花事；西方与现代卷补齐前，总分不可跨体系外推。
5. **应验记录的单源性**：应验多由占者本人书籍自述（verified_by 字段如实标注），无第三方旁证者占多数。
