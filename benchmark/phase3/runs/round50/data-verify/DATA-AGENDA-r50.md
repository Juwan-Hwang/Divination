## 二、夷坚版本源流待核（PREREG §12.2；只登记推进，不回改两卡）

対象：SS-001（甲志卷四·邵南神术）、SS-002（甲志卷十七·倪辉方技）两卡（存 runs/round48/digestion/cards-mining-sanshu/，封存副本见 masters-dataset 与 benchmark/phase3/data 登记）所据文本，与 hugbear 现行本（https://www.hugbear.net/hugbear/viewinfobook555.html，本轮本地副本 runs/round50/digestion/work-yijian-r50/yijian-full.html，邵南条 L271–272、倪辉条 L963–964）的实质差异。差异清单起点＝R49 supply-ledger YJ2-001..004 行 note。

### 结论

**所据本 identification：未定。** 可确证者仅两点：(1) 两卡文本与 hugbear 现行本有下述实质差异，非标点／简繁之别；(2) 两卡 provenance 字段自称「在线全文实取 hugbear……transcription=online-verbatim」，与实测不符——其 passage 文本并非 hugbear 现行本文字，SS-001 卡内且两本杂糅（见证据 3）。卡所据本究为点校本系统抑或他种在线转录，本轮以可及证据不能落定，候点校本／涵芬楼影印本扫描对勘。

### 证据链（差异逐项）

1. **条首身世句（邵南）**：hugbear 现行本作「邵南者。严州人。颇涉书记。好读天文五行志。邃于遁甲。占筮如神。然使酒尚气。好面折人。人皆谓之狂。宣和四年。游临安。」；SS-001 卡 context／passage 作「邵南。建昌南城人。隐于卜。邑人以神目之。」——籍贯（严州 ↔ 建昌南城）与生业评语全异，非异体字层面差异。
2. **批语层次（邵南·许子大侄案）**：hugbear 现行本只有一层——南批径为已解码语「令侄已出京。遇亲舅邀往西洛差遣。见托两火人受得官。之州当从水边。必滨州也。非县官曹官而又兼狱。必士曹掾也。」，无解码场面。SS-001 卡 passage_full 为两层——原批隐语「当得一差遣。过水门。见亲戚留之。索取两火人。自可得官。」＋子大读批解码段「子大读批。喟曰。虞意之也。已而曰。吾意侄已出京。遇亲舅邀往西洛差遣……」；且卡结局多 hugbear 所无之句「小五者寄食于戚家」（hugbear 结局径作「只托书铺家耳」）。
3. **SS-001 卡内杂糅（关键）**：卡 gold 的 statement_excerpt 录的是 hugbear 式批语（即证据 2 之一层本文字），passage_full 录的却是他本的两层文本——同一卡内两本并存。故「他本转录」之外，尚有建卡时以 hugbear 语改补／对齐断语摘录之痕；provenance 之「online-verbatim」对 passage 不成立、对断语摘录亦须注明来源混杂。
4. **倪辉条李／种诸案有无**：hugbear 现行本倪辉条条首作「成都人倪辉。妙于数术。」，正文径入靖康丁未虞窦布课，无邵氏子问动静、无辉先推京师之变前史、无李大谏／种太尉诸案；条尾另有绍兴二年冬虞允文过辉、辉自言入恶限、立春日果死一段。SS-002 卡则：context 作「眉山士人倪辉」「招邵氏子问倪辉动静，辉后至成都」「辉前已数推京师之变」，notes 明记「辉前此又有为李大谏、种太尉推数诸案」——此诸成分 hugbear 现行本全无。卡 statement「京城必以闰月陷。至五月一日。算复生。」与 hugbear 叙述式「京城苟不守。必以是月……今年五月一日。算当复生。」措辞亦异；惟结局句两本近同（「京师果以闰月陷。五月一日上即位于南京。赦书至成都。与辉筮日相去盖九十五日」）。
5. **卡 passage 的形态**：SS-002 passage_full 以省略号节录、且含「同为邵氏子」文理不通之残句，形态像自某种标点整理本摘录转记，而非自 hugbear 全页逐字移录；R48 MINING-sanshu-nondream-r48 所记页位（hugbear L186／L1094–1096）与本轮本地副本行位（L271–272／L963–964，整条各压缩于一两行）亦不合，行位口径无从对位。
6. **identification 尝试（阴性）**：2026-10-30 以标志语多式公开检索（「建昌南城人 隐于卜」「当得一差遣 过水门」「眉山士人 倪辉 李大谏 种太尉」「邵南 严州人」等），未检得任何与卡本文字相合的在线转录页（返回仅 hugbear、诗词无忧书目页等）；故「他种在线转录」一路无据可落。版本系统背景（只作候选登记）：hugbear 所收沈天佑序自言其本以闽板为正、摭浙（古杭）本补缺，且明言两本「详略不同……大同小异」，hugbear 现行本属此重刻复合本一系；通行点校本为中华书局 1981 年何卓点校本、以涵芬楼影印本为底本（日文维基《夷堅志》条目同载此说）。卡本的「眉山／邵氏子／李种诸案」等较繁成分是否即点校本（涵芬楼本）系统文字，须以点校本或影印本甲志卷四、卷十七扫描逐字对勘方能定谳，本轮未取得该扫描，**不落结论**。

### 处置建议

- 只登记：两卡 provenance 记为「自称 hugbear online-verbatim，经 R50 核查与 hugbear 现行本不合，所据本未定（候选：点校本／涵芬楼本系统）」，随主持 errata 或后轮数据议程落字；**两卡任何文本、已封存／入账状态一律不回改**（承 R49 ledger 口径）。
- 后续取证路径（供主持排期）：取得中华书局点校本（或涵芬楼《新校辑补夷坚志》影印本）甲志卷四「邵南神术」、卷十七「倪辉方技」两条扫描，逐字对勘条首身世句、批语层次、李／种诸案三项；三项全合则 identification 落定为该系统，仍不合则再查他种整理本。
- R50 本轮新建夷坚卡（YJ2 系及 §2 供给）以 hugbear 现行本逐字为准的口径不受本项影响，两本文字不得混用。

## 三、《宋史》马亮历官对勘（LK2-C02 开放项；PREREG §12.3）

对象：《宋史》卷二九八（列传第五十七）马亮本传历官序列中是否有「知江陵府」一任。R49 ADDENDUM-1 §1.2 登记：检索口径下未见、未做本传全文逐项对勘。

### 结论

**有——且凡两见。** 本传全文逐项对勘：马亮历官序列中明载「歷知虔洪二州、江陵府」一任，后文复载「徙江陵」再任。R49「检索未见」系检索口径漏检，全文对勘推翻之。对 LK2-C02 的含义：ADDENDUM §1.2 所列不利项 (3)「同名史传碰撞未决」中「历官未见知江陵府」一节应予更正——《梦占类考》原条以马亮知江陵（府）系事者，与本传历官不再相斥，同一性由「不能认定亦不能排除」转为「官历一节相合、同一性嫌疑上升」；但本传合辙只证明官历相容，**不单独证明**梦案主角即本传马亮，C02 污染维持 low-mid 与否请主持据此并入后轮 LK2 复议材料裁定（本席不径改裁定）。

### 证据链

1. **全文来源**：《宋史·列传·卷五十七》全文页（中华古诗文古书籍网 arteducation.com.tw，列传第五十七即卷二九八，篇目「彭乘 嵇颖 梅挚 司马池 李及 燕肃 蒋堂 刘夔 马亮 陈希亮」与卷二九八相合），2026-10-30 实取，马亮传全文在该页 L108–122，起「馬亮，字叔明，廬州合肥人。舉進士，為大理評事、知蕪湖縣……」迄「……子仲甫，為天章閣待制。」传文完整、历官可逐项读。URL：https://www.arteducation.com.tw/guwen/bookv_46653FD803893E4F5B252534B787668A.html
2. **第一见（决定性原文）**：「以右諫議大夫知廣州。……**歷知虔洪二州、江陵府**，再遷尚書工部侍郎，復知昇州，徙杭州，加集賢院學士。」（「歷知…江陵府」即知江陵府一任，与虔、洪二州并列于知广州之后、工部侍郎之前。）
3. **第二见**：「……明年，改兵部侍郎、知廬州，**徙江陵**，又徙江寧府。仁宗初，拜尚書右丞，復知廬州，召判尚書都省兼知審刑院，遷工部尚書、知亳州，又遷江寧府，以太子少保致仕，卒，贈尚書右僕射。」
4. **历官全序（逐项对勘摘录，供复议卷宗）**：大理评事·知芜湖县 → 殿中丞·通判常州 → 知濮州 → 福建路纠察刑狱官 → 太常博士·知福州 → 同提点三司都勾院·磨勘凭由司 → 知饶州 → 殿中侍御史 → 西川转运副使 → 直史馆 → 知潭州 → 徙昇州 → 右谏议大夫·知广州 → **历知虔州、洪州、江陵府** → 尚书工部侍郎 → 复知昇州 → 徙杭州·集贤院学士 → 御史中丞 → 兵部侍郎·知庐州 → **徙江陵** → 徙江宁府 → 尚书右丞 → 复知庐州 → 判尚书都省兼知审刑院 → 工部尚书·知亳州 → 迁江宁府 → 太子少保致仕。全序中「江陵」凡两见，无第三处；写作「江陵府」者一、「江陵」者一，均属知府／徙任语境。
5. **检索漏检成因登记**：此前检索多经二手小传摘要（如《隆平集》／《东都事略》系摘要作「歷知昇、廣、杭、廬、毫等州」，以「等州」略去虔、洪、江陵诸任），摘要口径下自然「未见」；本传全文则明载两任。此正 ADDENDUM 当时自注「未做本传全文与历官逐项对勘」所留的缺口，本项已补。
