## §3 第 3 类：格局成败与量级裁决

### 3.1 聚合依据（只引摘录）

- 主标 5/25（摘录 §五第 3 项），居第 2 类之后；摘录注明该类「含全表最深两例」（配对差 −6.00、−5.00 两例，编号已由主持在摘录中隐去，本件只引差值）。
- 类别内容（摘录 §五第 3 项）：成格判定门槛（生财链完整性一类）与量级区间上限的裁决口径——即本类由两个子层构成：成败判定层（门槛）与量级层（区间上限赋值）。
- 分数层关联：量级误差在评分上主要落入 claims／timing 的尺度部分；聚合摘录未给出第 3 类专属的层差拆分，本件不虚构拆分，只登记合并口径 claims −0.880、timing −1.010 为其所在层背景。

### 3.2 可立项形态（排队形态，非本轮立项）

- 候选形态限于类别级：成格判定门槛的裁决口径（成／败／救应的门槛条件）与量级区间上限的赋值口径两子项，须逐项单独归因、逐项立项，不打包为一个方法项。
- 成败判定子项与量级赋值子项须分开评估：前者是门槛判定，后者是第④步赋值，二者的口径成熟度不同（见 §3.3），不得以成败子项的相对清晰掩盖量级子项的未定案状态。

### 3.3 风险：量级层与 W↔子型三接口未定案的重叠（正面评估）

- 重叠事实：第 3 类的量级层（量级区间上限赋值）与六壬侧 W↔子型三接口中的子型三残余（量级档位／尺度赋值，D/E）同属「量级层未定案」地带——两体系的量级赋值都缺已定案的判别口径：何者属上游裁决翻转、何者属下游尺度赋值，在 R38 之前无跨体系一致的界定件。
- 双重未定风险（承 PREREG §2）：接口口径未定前叠加量级条文，将使后续归因无法区分「条文本身无效」与「口径归类漂移」两种失败，且八字侧量级条文一旦先行，会反向污染六壬侧接口带的跨轮同口径比较。此风险不是份额问题，份额再大也不能抵消口径未定。
- 本轮处置：W↔子型三接口界定已由 W-CHARTER（`runs/round38/diagnosis/W-CHARTER.md` §2）落盘，接口未定状态自本轮起转为「已定口径、待聚合证据复核」；但 W-CHARTER 的效力只及六壬归因口径，其判别键向八字量级层的可迁移性未经任何聚合证据检验，不得直接搬用为八字第 3 类的立项口径。

### 3.4 第 3 类立项的前置条件（写死）

1. 接口界定落盘——已满足：W-CHARTER 已成（本轮与本件同批落盘），§2 判别键、优先序与双报口径已定案。
2. R39 立项前须以聚合证据再评估，证据限于：(a) R38 平台轮八字段的聚合复标中，第 3 类主标／多标份额在同口径下是否仍居可立项量级（与本件所引主标 5/25 对照，只许同口径相比）；(b) 第 3 类两子项（成格门槛／量级上限）的可分离性聚合证据——若聚合材料仍无法将量级赋值与成败判定分开计数，则只许先立成格门槛子项，量级子项继续排队；(c) W-CHARTER §2 判别键对八字量级例的适用性聚合检验（以聚合计数报告，不以逐例立规）。
3. 三项中任一不满足，第 3 类在 R39 继续排队，不降格立项、不与他类打包搭车。

## §4 排队结论与判据

| 队列 | 类别 | 处置 |
|---|---|---|
| 本轮（R38） | 第 2 类 取用／扶抑裁决 | 取为唯一方法项 BZ-FY（PREREG §2 已定） |
| 下一轮（R39） | 第 3 类 格局成败与量级裁决 | 排队；按 §3.4 前置条件再评估后逐项立项 |

判据（写明）：

1. **聚合份额序**：第 2 类主标 6/25、多标 7/25，居第 3 类主标 5/25 之前；且第 2 类有「同源机制成对出现」的类别形态证据，第 3 类的最深两例（−6.00、−5.00）是深度证据而非份额证据，深度不替代份额作排队首位依据。
2. **口径成熟度**：第 2 类的处置形态（病字定位、反扶抑判别、裁决顺序）可回扣章内既有条文与典籍原文，口径自足；第 3 类量级层与 W↔子型三接口同属未定案地带（§3.3），口径不自足。
3. **传导位置**：第 2 类居 direction 差的上游且传导关系已由摘录注记定性（上游裁决错误传导），先处置上游可使后续轮次对第 3 类的归因更干净；第 3 类的量级层在下游赋值步，早上游未清时立项将混杂归因。
4. **单方法项纪律**：本轮方法改动只限一项（PREREG §0），两类同立即丧逐项归因；排队是归因纪律的要求，非重要性排序——第 3 类排 R39 不表示其份额或深度不重要。
