- **建包脚本适配逐处核对（R81/R83 判例增补一）**：建包脚本内嵌的显式 id 清单属逐轮实值，适配时与 GOLD 路径、分段断言并列逐处核对；首跑断言拦截先查适配误伤、再查数据。

- **聚合件读取防逐例行文回带（R85 修订席判例，本轮明文）**：凡派单限定「只收聚合」之席位（§3 修订席、诊断附读引用之属），其对聚合件的检索只许定位聚合节标题、计数行与分段聚合表，不得以逐例归因行文为检索命中对象、不得将逐例行文带入产出依据；派单中明示此限，产出件中聚合引用逐项可溯至聚合节。
- **中间件只许本轮目录内**（R61 X2 事件教训；R72 Y4 自报后明文重申）：各席一切脚本与中间文件（含只读转录文本、**阅读转储**）一律置于 runs/round90/ 内本席唯一名文件；**禁用 /tmp——禁令涵盖只读转录、阅读转储、探针类动作与工具自动溢存**（工具基础设施自动转存非席位行为者，按 R75 登记口径只登记、不归责席位；发生即当轮登记裁记，承 R81 B11／R83／R84／R85／R86／R87／R88／R89 判例）。
- **席位脚本禁通配删除**（R64 判例一）：任何席位脚本不得使用通配删除/覆写（如 rm 通配、glob 批量删除）；**半成品定点删除重跑须逐件登记**（R88 判例：精确单文件路径删除自产未完成件后修正重跑，逐件入 ADDENDUM）；产出逐件按本批 id 清单精确处理；构建脚本的 glob 须排除本轮产出目录自身文件以免自吞（R64 判例二）。**收束提交逐件点名 add 后回读清单验齐；误扫书页图类（版权扫描件）即时以更正提交撤出索引、文件留盘未跟踪**（R82 why-pages 判例）；收束与构建 glob 均须排除书页图目录（expansion*/work-*、*-pages 之属）。

- **补派逐字原单（R83 判例增补三）**：原席 errored 且零产出时，可自其会话记录取回原派单逐字补派，派单内容一字不改；补派前须间隔复查盘上产出实况确认零产出。
- **引用文本落盘验尾**（R66 判例，源出 R65 PREREG 截断勘误）：凡以工具输出/他轮文档为源撰写或转写文件，禁止以被截断的输出为源；长文分段落盘、每段落盘后回读字节数与尾行核验，全文写毕回读首尾与小节标题清单验齐后才许提交。**落盘截断件处置（承历轮判例）**：席位产出件经主持验盘发现截断者，该件不成立；席位以经验合（断言/对勘）拒绝截断源后，回原件重做并重落盘，主持复验后才记完成。
- **写盘断言标配**：席位脚本与产出均带例数/id 集断言；主持冻结前逐席验盘，回传数字不作证据；各席回传一律附产出件绝对路径与字节数，主持逐件回读核对后方记完成。**查盘未见文件不得立即判未落盘，须间隔复查一次再行重派**（R59 仲裁事件教训）；「回传有、盘上无」经复查确认者才判真未落盘并重派；「回传截断、盘上完整」以盘上件为准只登记；「回传截断、盘上全缺」拆单批补派全新席（判例链 R61 S4／R63 S5／R66 S5／R67 S4／R69 S9／R75 S5）。**席位以 completed 终局但无回传正文时，先盘查目标产出文件实况再定补派**（R82 judgeY2 判例）。
