# 严肃占卜知识库（Divination Knowledge Base）

目标：不是「会算」，是**算得与公认大师尽可能一致**。全库围绕对标校准（`calibration.md`）与大师成例盲测（`benchmark/`）运转，配套可复现的随机工具（`tools/`）与实际下载到本地的典籍全文、开源代码与数据集（`sources/`、`tools/repos/`、`tools/datasets/`，总清单 `MANIFEST.md`）。

## 总则（2026-10-29 用户最终定调，覆盖一切旧口径）
1. **唯一总目标**：盲测中与大师结果尽可能一致、尽可能多地通过测试集（协议与量表见 `benchmark/PROTOCOL.md`）。
2. **来源分级只作标注、不作门槛**：A 原典 / B 权威注本 / C 现代学术 / D 现代整理 / E 民间说法——标明出身即可。现代建构与伪托只要是大师实际奉行、按之作断的（如托名邵雍的《梅花易数》、本属现代建构的 Waite 牌义），照常收录为对标依据，但出处真伪必须照实标注，不许假装真古籍。
3. **暂不采用清单**（MANIFEST 末节）：只留既无大师背书、又明显让结果偏离大师的条目；测试证明有用的可移回收录，以结果为准、不以出身为准。
4. **方法无关**：验证只对齐结果（结论方向、关键具体断语、应验）；用中国理论算出与西方大师相同的结论同样算准；跨体系收敛是加分信号。实占时以问题与对象为准自由选法/混用。
5. **分歧由算者自决**：流派与约定之争不推回求测者（默认表见 `calibration.md` 第三节）；输出末尾一句话交代所用之法即可；只有事实性输入缺失（所问何事、出生时辰、出生地）才发问。
6. **测试集防自欺**：校准集（答案开放）调规则、留出集（答案封存）定成绩，七三开，benchmark 统一管。

## 严肃占卜流程规范（每次必走）
1. **复述问题确认**：把所问之事复述给求测者核对（一事、一问、可判定），确认后才起卦/排盘。
2. **一事一占**：同一事不重复占；已占之事只复盘、不再占（《周易·蒙》「初筮告，再三渎，渎则不告」为此规的典籍出处）。
3. **原始结果先行**：卦象/牌面/盘面完整呈现（逐爻、逐牌、逐宫），然后才许解读。
4. **逐条回扣**：每条断语回扣基准规则或典籍成例（基准表见 calibration.md 第一节）；回扣不上的标「推测」或删去。
5. **结论形态**：给倾向 + 条件 + 应期/关键变量，不作绝对断言；多法同指一处时明说「几条路都指到同一处」，冲突时呈现分歧并说明自己的取舍理由。
6. **记录归档**：时间（干支与公历）、原问、原始结果、所用之法、断语、（日后）应验回填——格式见 skill。

## 资料处理规矩（扫描件/古籍转录）
扫描件与古籍影印里 OCR 读不出的内容（盘图、speculum、题头、手写字等），改用多模态视觉读图转录，不许因 OCR 失败就放弃、更不许臆补：转录条目须标注 transcription=visual 并给置信度；关键数据（出生时刻、干支、度数）必须与上下文规则交叉验证（如干支与日期是否自洽、度数与宫位是否相容），验证不过的标低置信并注明。纯文本 OCR 成功的内容标 transcription=ocr 或不标。

## 娱乐与决策的边界
占卜在本库是文化传统与决策参考框架，不是科学预测工具：典籍成例有幸存者偏差，盲测达标证明的是断法与大师一致、不证明预测效力。重大决定（医疗、法律、投资、人身安全）只许作参考输入之一，必须叠加现实专业判断；涉及他人命运的断语不下定论；不提供任何「改命/破解」类收费式话术。
