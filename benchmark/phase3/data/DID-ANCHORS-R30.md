## 五、结论

1. **双锚稳定：同带。** S 集轮间差 +0.278（SE 0.269）与 C 集轮间差 +0.176（SE 0.066）之差仅 0.102，其 SE＝√(0.269²＋0.066²)≈0.277，差值不足 0.4 个 SE——两集的「R29 方法增补＋轮间噪声」效应落在同一带内，无证据显示 S 集对方法增补有异于全池的特殊敏感性。注意 S 集 SE 大（n=44 且长尾），「同带」是弱证据：它排除的是大效应差异，不排除 ±0.5 量级内的集间差异。
2. **下轮 inputs10 的 DiD 同法锚必须用 R28、不得用 R29。** 论证：现行活方法＝R28 口径（提炼后方法快照）；R29 唯一变量是裁决增补、且增补已回滚，下轮作断方法与 R28 相同、与 R29 不同。用 R29 作锚会把已回滚的裁决增补效应（全池约 +0.18～+0.28）误记为 inputs10 的输入效应。具体锚值：S 集 R28 配对差 **−1.261（SE 0.315）** 为切换集锚；C 集 R28 配对差 **−1.174（SE 0.114）** 为对照集锚。下轮 DiD＝(S_new − (−1.261)) − (C_new − (−1.174))，其中 C_new 须在下轮同法重跑 C 集后取得。
3. **预期噪声带宽（下轮 DiD 判读用）**：以本轮实测轮间波动为准——S 集（n=44）单轮配对差 SE 约 0.28–0.32、轮间差 SE 0.269，即 S 集均值在无任何真实变化时两轮间可自然漂移约 **±0.53（≈2SE）**；DiD 合成 SE 下限约 √(0.269²＋0.066²)≈0.28，实际下轮 DiD 还叠加新一轮评审噪声，判读带宽建议按 **±0.55（约 2×DiD SE）** 起步：|DiD|＜0.55 一律记未定带，不许称输入效应有效或无效。
4. 附注：R29 方法增补在两集上的净效应均为正（S +0.278、C +0.176），与 R29 全池配对差改善（−1.227→−1.014）方向一致；此为轮间读数登记，不构成对已回滚增补的重新裁决——是否恢复裁决属主持角事项，本计算不预判。
