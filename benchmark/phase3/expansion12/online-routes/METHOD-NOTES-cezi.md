## 一、总纲（卷一卷首）

- 引邵子（邵雍）二语为纲：「认定用神」「体立而后用行」。
- 立法理由：「测不立法，不足以示学者之权衡；字不加减，不足以开问者之蒙昧。是必乘除损益，每一字到真机，流动变化数字于其间，则所问之事昭然在目。」
- 断吉凶总则（卷三取格法）：「法先详其五行生克，次观其六神动静。假若五行相生、六爻安静，则取吉格断之，否则以凶格断之。」——测字取格借用了六爻的五行生克与六神/六爻安静概念，是与六爻体系的接口处，建章时须注明。

## 二、测字十法（卷一）

| 法门 | 定义（原文要旨） | 例（原文） |
|---|---|---|
| 装头 | 所写之字吉凶隐露而首犹藏，如神龙不见首；添笔于上出之，字理全彰 | 戊→茂、里→童、古→罟/苦/居 |
| 接脚 | 字如人体有冠必有履；全身已现未举足，加笔于下以行之 | 采→悉/释/番、千→秀/壬 |
| 穿心 | 字画端正左右俱全者，从中穿入数笔变化之 | 文→吏、昌→量、月→舟/用/冉/角 |
| 包笼 | 全体不动，将笔周围包裹之，另成一字 | 稚→灊、贝→遗/测、里→墨 |
| 破解 | 破：字体段分开加入数笔成字；解：笔画抉出从旁标比评论成文。「破易而解难，破平正而解奇幻」；破须分开，与穿心（字体不动）不同 | 行→术/衙/衍、辛→章 |
| 添笔 | 「当添亦添，当减亦减。添乃补不足，减乃损有余」 | 唯→难、王→玉/弄/全/旺 |
| 减笔 | 非事之当理之正不可漫用；当略减，防混入摘字法 | 宽→苋/见、莫→草 |
| 对关 | 专取头足首尾：合则如门之闭，分开云某头某脚则如门之开。「为字中第一要义」 | 先（牛头虎足）、善（美头喜足）、友（有头没尾） |
| 摘字 | 遇指点刻划处，摘字中一二笔画以断；旁人言语、万物影响皆可借用 | 哉（土、戈）、谋（小、口） |
| 观梅测字 | 邵子心诀：心镜光明、随物洞照。先立九法为程式，此为活法；无物之字则审来意与字到时上下左右远近之影响借用，否则拆字 | 天/地/人/日/月/金/木/水/火/土十字通则（如「天：凡事空虚，然利于行动，问功名宜晴朗之日」） |

## 三、心易六法（卷二，借六书之名）

| 法门 | 要旨与例 |
|---|---|
| 象形 | 三路：以字象物（乙似鱼钩、弓似蛇）、以字象字（芒似破［衣］、贵似破柜）、以意象字（辛似幸、夫似失、因似良）。取象为全书最常用法门，卷七成例多属此类（如门为「日有余、月不足」之形断病死、芍为「花残月缺」之形断少妇亡） |
| 会意 | 以合成之意象成断：烟（因风吹火，事必借力方成）、淋（楚汉争锋，主口角是非）、逢（劈破莲蓬，子必见伤）、炉（百病丛生，骤然更变，并逐项释「百病」所指） |
| 假借 | 借时令：旦借春、千借夏、甲借秋、夕借冬（一日借四时）。借人事事物（即外应）：立逢人借为位、遇水借为泣、有女为妾；口见鸟过有欲鸣之象、心闻音乐定然得意。卷七弦字、公字等例的「旁人/旁事」断法出于此 |
| 谐声 | 以音同/音近转义：倒到、秤称、叉差、加家、非飞、桃逃、梨离；莺与阴同音，问晴雨主天阴 |
| 指事 | 「因其事而断」，即散格、双句格之法；必审情性、察动静、明踪迹。内分十法：观人、察色、辨言、辨事、察墨、辨纸、观时、相机、正论勿好奇、言语不可杂——此为测字的「审问/察言观色」规程，建章时不可漏 |
| 转注 | 一字多音多义随机应变：为（平/去）、行（蘅/杭/沆/慎）、王（平/旺）、长（场/障/掌/仗）、夫（平/扶）。典型断法：临字问病读去声为「临丧」断不吉；王字问求财读去声为「旺相」 |

## 四、取格与格法（卷三至卷六）

- 卷三 测字取格大法：「凡一字之来，用一语判之，谓之取格，如文章人品之有定论。」断语须「出经入史，搜神剔髓」；自称「今将既验之语分类录后」——按部首/字类（氵、金、木、土等）汇列单字＋四字格断语（如 泄「御沟红叶」、江「功名源远、财源半空」）。**注意：此卷只有格语、无案例与应验记录，不得当成例用**（普查定案见 CENSUS-NOTES）。
- 卷四 双句格法、卷五 测字散格法：双句/散句体断语格汇编（指事法自注「此则散格、双句格之法也」），体例同卷三，为断语辞库而非案例。
- 卷六 杂占赋：赋体杂占歌诀。

## 五、卷七成例中反复出现的断法（自 54 则归纳，供建章取材）

1. **加笔成字定事**：欠加两点为「次」断非首胎、加土为「坎」（中男）断生男，且以占日初十「加十一在旁成坎」定当日产（CZ-001）。
2. **笔数奇偶定男女**：元字四笔属偶断生女、三笔属奇断生男；并引邵康节语立「一字之机」总则：「字同事不同，不宜此而宜彼；事同字不同，倏变吉而变凶」（CZ-008/009）——同字异断的合法性依据在此，建章须收。
3. **拆字定向/定身份**：齿以「齿为年数、无三十七齿之人」断行人死（CZ-016）；唯以「前呼后拥」断道员（CZ-030）；求财二字以「皆有木形」断卖果子、以字形断路线与亏折史（CZ-020，双字测）。
4. **神煞象入断**：吊客当头、丧门煞局（张字，CZ-005）；黄幡豹尾（芍字，CZ-023，应验日复核「箕水豹值日」）；螣蛇/玄武合断伙友别投（弦字，CZ-017）。
5. **应期断法**：日期型（立春前五日成婚，虬字 CZ-018）、干支型（逢辛日/辛月险，幸字 CZ-011；逢土日愈，病字 CZ-014）、时序型（明晨当至，衡字 CZ-022；次日产，CZ-001）、数日型（难过五日，亥字 CZ-004）。
6. **方位断**：高字以「庚辛起手」断店面在西南方（CZ-031）；麟字以「纯水之形」断不利南、宜往北（CZ-012）。
7. **指事/献策型**：子字例断后给出处置方案（一月后按策成事，CZ-021）；恙字例断「穷寇勿追、静以待之」（CZ-026）。此类例的「断」含行动建议，评分口径如何处理请主持在建章时一并裁定。
8. **现状确认型断法**：终身命例型（麟、笔）与诊断型（焉字瘫症）断的是已然事实、由对象当场印证，与八字命例以生平为结局同构，建章时宜单列一类说明。

## 六、与既有体系的关系（供主持参考）

- 测字与本库既有六爻/梅花不同：输入不是卦象而是**求测者所书之字＋书写情境（笔数、墨色、旁人旁事、占时）**，输入卡字段需含所书字、笔数（可考时）、所问事项、占时与外应；卷七原文多未记占时干支，建卡口径请主持裁定（本批 cases.jsonl 已逐例注明「原文未记」处）。
- 取格法借六爻五行生克与六神概念（§一），但卷七成例实际断法以取象/拆字/谐音/加减笔/奇偶/外应为主，六爻式推演在成例中罕见——建章时应以成例实际用法为准，勿以卷三总则压成例。
