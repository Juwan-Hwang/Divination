- 來源：華夏大易學社 cnddy.com 在線全本（https://www.cnddy.com/1759.html），2026-10-29 在線逐頁讀核第十一至十七問（只在線讀、未批量抓取，合 PROTOCOL 合法性口徑）。頁面為**簡體字形**，節錄照頁面錄入，不做簡轉繁（避免偽造逐字節錄）；此為與第一輪（繁體錄入）的字形差異，屬已知數據質量提示。

- 裝卦：頁面雙欄裝卦表 OCR 行序錯亂，逐爻不可靠還原——同第一輪口徑，只錄卦名/卦宮/空亡/用神等可互證項，attachments 附 chart_note，逐爻表不錄、絕不臆補。

## 成色標記

- LY-324 友父病：卦名頁面作「水雷屯之震為木」，「震為木」不成卦名，疑為「震為雷」之誤，inputs 卦名欄兩說並記。
- LY-329 開店：應驗句頁面作「果俗底」，「俗」疑為「年」（年底）之形誤，照錄並注。
- LY-333 子久病：斷語兩可——同段先斷「本日應見凶」，又以子水暗動改斷「今日不死、次日當防」，實際死於本日辰時；兩說並錄不挑拚，為應期/斷語含混度的真實樣本。
- LY-334 同鄉借貸：應驗句首頁面作「不徒」，疑為「不聽」，照錄並注。
- LY-344 子久出：頁面占題作「何日沖」，疑「回」之誤，已注。
- LY-345 子嗣多否：斷語「不但狠藉」之「狠藉」義不可通，疑有訛字，照錄並注。

## 被拒（第十一至十七問）

- 僅「果驗」總括無具體結局（B）：第十一問借銀、失銀物；第十二問何日得財、妻病、子病、生產；第十三問文書何日到；第十五問子嗣、雨久傷麥；第十七問子何日脫難（且與增刪 857 例同案，增刪版已收 LY-419）。
- 無結局事件/結局過簡：第十一問出外貿易、自占婚姻（結局僅「此女病故」含糊）；第十二問誤軍糧被參（結局無時點且弱）。
- 結局文義殘缺：第十二問劾奏他人（「果題淮究奸」殘缺）；第十三問趕去寄信（文義殘缺）。
- 非占後應驗：第十二問子在楚/侄平安（所謂結局是占前已傳聞的覆舟死訊、且求測者自承戲卜試師）；第十六問造墳葬（當場報石塊，無占後應驗事件）。
- 斷語在斷曰內自證（B）：第十三問自及子被拿問（「累俱受重刑」在斷曰內）。
- 已收不重複：第十四問侄孫病＝LY-317；第十五問開煤窟＝LY-318（與增刪版開煤例同案異本，增刪版已撤，見 README 去重記錄）；第十五問女病與增刪 808 例同案且頁面作「果驗」，雙因不收；第十七問求財＝LY-319、升遷＝LY-320。
