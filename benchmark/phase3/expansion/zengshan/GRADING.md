# GRADING — 《增刪卜易》卷三、卷四六爻案例增補（Phase 3 數據角）

收錄 **59 例**（LY-201–LY-259）：卷之三 36 例、卷之四 23 例；結局可得性 **A 級 59 例、B 級 0 例**；污染分層 **低 59 例、高 0 例**；應驗時點明確 **53 例**。

## 分級口徑

- **A**：原文明確記載可與斷語分離的實際結果事件（果……／後……等追記句），本批全數為 A。
- **B**：只有大師自述式應驗、不可分離——本批不收（篩選時剔除，見篩選日誌）。
- **污染**：本批皆清初民間占例、求測者多未具名、結局無從以常識先驗得知，一律低污染；無著名歷史人物／事件例，故高污染 0 例。
- **應驗時點明確**：應驗追記含具體日／月／年／時辰（如「果於巳日到」「果至卯年立業成家」），或斷語給出 bounded 窗口而應驗落在窗內（如「不出五載」）。

## 卦象覆核方法（防手算誤改）

全部裝卦曾以程序按爻位陰陽（⚊/○為陽、⚋/ㄨ為陰，動爻翻轉得變卦）逐例覆算本卦／變卦名，與原文題面卦名逐一對照：59 例中 58 例全合；唯一不合為 LY-253（原文 4119 行）變卦卦名「否」與裝卦（咸）不合，已在該例 notes 並記兩說、裝卦照錄不改。另 LY-202、LY-225 兩例原文未直書卦名，據裝卦推得並已注明。覆核中曾發現手算誤判多例（如巽之姤、解之震、中孚之臨皆原文正確），故卦名字段一律以原文題面為準，不作手算「訂正」。

## 篩選日誌

逐章通讀卷之三（身命章第三十六至求財章第六十八）、卷之四（謁貴章第六十九至新亡附葬祖塋章第一百三十）全文，識別候選占例 **105 則**（多卦合占按一例計），收錄 **59 則**，棄 **46 則**。棄因分類：
- 無應驗追記、或只有理論評註無結果事件：9 則（如占壽中孚例只有「二十年後再占」之約、家宅乾之小畜例純為駁古法、占何時得地例斷後無果句）
- 月日干支缺損或訛損、四要素之占時不全：7 則（如寅月癸女日、卯月戌辰日、寅月亥日無干、酉日戊寅日等）
- 卦名原文未書且推定不穩、或多卦鏈過長不合單例 schema：6 則（如醫卜往治五卦鏈、品級章多卦混敘例）
- 斷驗混敘不可分離（相當於 B 級）：6 則（如祖母痰堵例先報已逝後救活、歲考泰卦例斷驗同段、舟行蠱之巽例途中悟卦追敘）
- 終身泛斷、應驗為一生梗概不可分離核驗：7 則（終身財福章中段多例屬此）
- 四要素俱全但應期與資訊較弱、名額內取捨：11 則

另：与已收 LY-001–LY-036 按（占時＋卦象）逐一比對，無重複收錄（同主題如占父何日回、占升遷者，占時與卦象皆不同，為不同占例）。
