# Divination（严肃占卜）

## 总目标（先于一切细则）
**唯一标准：结果与公认大师尽可能一致。**
- 验收方式是盲测对标（见 `references/PROTOCOL.md`）：把大师当时情景喂给不知结果的一方，只看最终结果的接近程度（结论方向、关键具体断语、应验对齐）定成败；方法、体系、流派不拘，中西可混用，跨体系算出同一结论同样算准，且是加分信号。
- 来源分级 A 原典 / B 权威注本 / C 现代学术 / D 现代整理 / E 民间说法**只作标注、不作收录门槛**：现代建构与伪托只要是大师实际奉行按之作断的（如托名《梅花易数》、Waite 牌义），照常用作对标依据，但出处真伪必须照实标注，不许假装真古籍。
- 只有既无大师背书、又明显让结果偏离大师的内容才不用（清单见 MANIFEST「暂不采用清单」）；解卦时不得引用清单条目为依据。

## 起占前：确认（只问事实，不问选择）
1. **复述问题**：把所问之事复述给求测者核对——一事、一问、可判定（「这次 offer 该不该接」合格；「我的未来怎么样」须收窄）。确认后才起卦/排盘。
2. **只许补问事实性输入**：所问何事、出生年月日时、出生地、性别（命盘类）。**不许**把流派/约定选择题抛给求测者（「您想用立春还是春节换年？」是违规问法）。
3. 一事一占：同一事已占过的，只复盘旧记录，不重新起卦（《周易·蒙》「再三渎」）。

## 选法与约定：算者自决（默认表，不向用户列选项）
按问题与对象自决，可混用多法互参：
- 具体一事成败/应期 → 六爻纳甲；即时决断 → 梅花；方向与自省 → 周易文本占；一生格局/周期 → 八字（紫微互参）；择时择向 → 奇门；关系与心理叙事 → 塔罗；出生图式/行运 → 西洋占星。
- 具体一事的**细节推演/来龙去脉、多人多事牵连** → 大六壬；与六爻互参口径：同一事两法同占时，成败方向以两盘收敛处为准，细节（何人、何方、何时、经何过程）以六壬三传天将链补六爻之略；两盘方向冲突时如实呈现分歧并写明取舍，不许只取一盘压另一盘。行人、失物、官讼、兵斗类细断以六壬为首选。
- 八字默认：立春换年、节气换月、23 时换日、出生地明确时用真太阳时（夏令时先回调）。紫微默认：《全书》系四化（庚/壬化科分歧从全书）。凯尔特十字默认 Waite 原文位序。起卦默认铜钱概率（蓍草仪轨须用户明示且声明改口径）。占星本命默认 Placidus、古典问题默认整宫。完整默认表与理由见 `references/calibration.md` 第三节。
- 输出时只在末尾用**一句话**交代所用之法（如「本盘按子平正统：立春换年、真太阳时校正」），不列选项、不解释分歧全貌（用户追问时再展开）。
- 多法指向同一结论：明确告诉求测者「几条路都指到同一处」以增强置信；指向冲突：如实呈现分歧，并说明自己最终取舍与理由——取舍是算者的责任。

## 各占法流程（细节查对应知识库篇，含精通检查表）
- **周易文本占**：`tools/cast_iching.py "原问"` 起卦 → 按动爻数走朱熹读辞规则（0 动卦辞、1 动爻辞、2 动两爻以上为主、3 动两卦辞参读、4 动变卦不变爻以下为主、5 动变卦唯一不变爻、6 动变卦卦辞）→ 逐字引原文再落断。
- **六爻纳甲**：同上得卦 → 装卦五步（定宫、纳支、世应、六亲、按日干安六神）→ 选用神（财/官/父/子/兄按所问）→ 旺衰（月建日辰为纲）→ 动爻与原神忌神链 → 成败与应期（应期按（a）（h）六爻双层表达落定（窗口＋窗口内主坐标），事件型终局按通则（l）单判，病占／行人类收束前过（f）应验对象复述）；**门类应期查表校准（六爻应期，机制级）**：应期三步与合流 D 项四路扫查生成候选后、定窗口内主坐标前，按本题问事门类查 `references/chinese-liuyao-meihua.md`「门类应期对表」校准——对表首选机制在候选集内有点时，主坐标优先取该点，首选无点才递补对表次选机制；对表取法与闸门状态（空／墓／破／合住）的释放规则冲突时，闸门释放规则优先、对表次之，即先等闸门开释之支、再在开释后的候选内按对表取点，不许以对表跳过尚未开释的闸门状态；查表取舍须在断语依据中写明（查了何门类、首选机制为何、取中或未取中及其理由）；本题门类不在对表内者，明写「对表无此门类」，按三步＋D 原序定主坐标，不许类推套用他门类条文；查表校准后、定主坐标前，首选与次选候选属于不同尺度、或同尺度相距超过一个单位步进者，须按 `references/chinese-liuyao-meihua.md`「应期对决（双候选比较裁决，六爻）」执行双候选对决取点（两候选同尺度且相距 ≤1 个单位步进者不对决、按原序取点，对决不预设尺度、不授予任何机制排他权）；下终局断语前须过知识库篇「终局反转信号扫查——完整判据链门槛」（三类信号判据全部成立才许翻转初判终局，部分成立只许降格/留余地、禁止反向断终局），疾病类涉病位者另过「病位取象复核」依据链。装卦后拿 benchmark 古例排盘口径自检；**开源装卦库是空白，不许拿来路不明的在线排盘结果直接用**。
- **大六壬**：起课/复核盘面（月将加时、干寄宫、四课定位、贵人昼夜起例与顺逆、九宗取传，见 `references/chinese-liuren.md` 第一、二节）→ 取类神（按所问门类定类神：日干为己、日支为对方/宅、年命为本人根基，第五节）→ 读三传生克链与天将乘传（第四节）并核课格主向（第三节）→ 走分类占断对应门（第六节：行人/失物走失/贼盗/官讼/疾病/婚姻/求财/出行/仕宦功名含考试/孕产/兵斗/章奏钦差）→ 应期走第七节六壬三路（逢值/逢冲合/出空填实），合通则（a）（h）（k）以窗口＋窗口内主坐标双层表达落定。盘面不全（只有课式名、三传含天将、干支占时与空亡，无天盘全图与四课全列）时守第八节：只据干支、三传链、天将乘传、课格名、空亡落处作断，不臆补天盘全图、四课细节、神煞全表与未给的年命；作断后过第九节精通检查表。**象组检核强制回填（流程层，定稿前必经）**：落终局方向与量级档位之前，basis 必须先完成「象组检核」回填——按本题所属门类，把 `references/chinese-liuren.md` 第六节该门的象组/判据件逐件列出，逐件标注三态（**在**／**不在**／**无据**）并注明盘面出处（何课、何传、何将、乘何神）；有专属象组之门不得整组略过：官讼门查遇赦开豁识别组（§六.4）、疾病门查致死象组（§六.5）、出行门查险量分级件（§六.8）、一课多占逐事分断（§六.13）；无专属象组之门，回填该门判据件并逐项核对第九节精通检查表。**未回填齐不得定稿**——象组未枚举到底之前，不许先定终局方向与量级档位；判「不在」须指明盘面何处可证其不在，判「无据」须写明缺何字段，不许以未查充不在。终局方向与量级档位必须能指回检核表中已回填之件；与检核结果相悖而落断者，须在 basis 写明相悖理由，否则该断不成立、回检核重定。
- **梅花**：时间/数字/物象/声音起卦（公式见知识库篇，后天起卦动爻须加时数）→ 定体用 → 生克五诀+旺衰+外应 → 断语须过「明理」一关（推数又须明理），并过作断通则「（d）爻辞取象核对」「（e）事实优先序」「（f）应验对象定位复核」「（g）具体断语密度」四关（引辞先核辞义、收束逐项对回占题事实、逐条核对承受对象与应验对象同一、主断语落到人物/物品/数量/应期数字至少一项，细则见知识库篇梅花篇同名诸节与本节（g））。
- **八字**：历算只许用 lunar-python/sxtwl（先交叉核对四柱一致才解读）→ 调候先行、格局定体、旺衰定量合参 → 大运流年引动断应期。**禁止** lifekline 式做法：不许让模型直编逐年分数、不许用「强造波动」类提示词（见 references/lifekline-method.md）。
- **紫微**：iztro 排盘（农历换算注明）→ 命宫手算公式复核 → 三合为体、四化为用；四化版本在盘后一句话注明全书系。
- **塔罗**：定牌阵 → `tools/draw_tarot.py` 抽牌 → 牌义只以 Waite《Pictorial Key》原文为准（本地全文），关键词表（tarot-78.json）只作索引；凯尔特十字用 Waite 位序；逆位默认启用。

## 作断通则（跨体系必经十二条，任何占法作断时执行）
- **（a）应期定点**：凡给出应期，必须同时写明两样——**单位**（日 / 月 / 年 / 运，四选其明确一档，不得含混写「近期」「亥时亥日之类跨单位混写」）与**依据**（走的哪条推得路径，如六爻填实/冲空/出墓、八字运年引动何字、占星行运何时成相）。单位由**占问的时间尺度**决定：问近病、近事成败取日/月，问升迁仕途取月/年，问一生运程取运/年；尺度与单位不匹配（如以「日」答一生之问、以「运」答近病之问）视为未定点。**回溯类**（已知结果反推何时发生）先定年、再定月、最后才细化到日，年未定准不许先报月日。应期与成败分开写：先有成败结论与路径，才有该路径上的应期，不许拿应期代替成败判断。**应期双层表达（事件型占断，判定内容，非格式段落）**：事件型占断（六爻为主，含梅花／卜筮类事件断）的 timing 改为双层表达——**第一层写窗口**：窗口由卦理推出（六爻以用神值日／值旬、动爻、世应等为据），宽度按所问尺度定——日内／即时事给具体日窗（如「三日内」）、旬月事给旬窗或月窗，窗口的推出依据写入 reasoning 并留痕；**第二层写窗口内的主坐标**：在窗口内只许一条主坐标（单一日／时，为最可能应点），不许并陈两个主坐标供人自选，三路候选中未被取中者只许写入 reasoning 并逐路注明舍弃理由。**禁止以无限宽窗口对冲**：窗口宽度不得超过所问尺度本身（如问「本月内能否办成」窗口不得宽于本月；问近病窗口以旬为上限量级），窗口若宽到与问题尺度同级，视为未给应期。**命造类不适用本条**：八字／紫微等运档尺度维持原运档表达，不套窗口＋主坐标。此条只定 timing 的表达层数与主坐标取舍，是对 timing 内容的规定，不新设任何输出段落（取舍落法见（h）与 `references/chinese-liuyao-meihua.md`「应期三步（六爻本地化）」：按用神状态综合判断取一舍二并写明理由，不查表定序）。
- **（b）等级校准**：断语的**等级**（如仕途至州牧/封疆/仅入仕、罪至入狱/重罪/死罪、富至大富/小康/仅得财、病至可愈/重危/不治）必须与格局/用神的**强度同级**：格局已成、用神旺相有根有救时，断语按该强度足级给出；格局破损、用神休囚无救时，才按弱级给出。**降格必须写明压制依据**——指出具体哪一字/哪一爻/哪一相位压住了等级（被冲破的用神、无根的格局、克泄无救等），写不出压制依据的降格一律撤销、回到与强度同级。升格同理：超出格局/用神强度拔高等级，须写明提格依据。禁止无据的保守降格（如一律往轻里断、一律加衰尾），也禁止无据拔高；等级是断语的一部分，与方向同等计较。
- **（c）事件级断语**：梅花/外应及**一切体系**，断语必须落到**事件级**——具体的人 / 事 / 物 + 程度或数量感（如何人来、何事发生、何物出现、程度轻重），只给「大吉」「先惊后安」「有血光之灾」一类空泛吉凶象意，视为**未完成作断**，必须继续推到事件级才许交付。推法回各自知识库：梅花以体用生克 + 外应物象 + 情理（明理）收束到具体事象，六爻以用神/六亲/六神落到具体人事，八字以十神宫位落到具体领域事件；实在推不出事件级的，须明写「此象只能定到吉凶层级，事件级推不出，依据不足」并降置信，不许用空泛断语冒充完成。
- **（d）爻辞取象核对**：引用爻辞/卦辞作断时，**断语的吉凶方向必须与该辞在原书中的吉凶一致**——《周易》经文之辞自带吉、凶、悔、吝、厉、无咎之断，引辞即受辞义约束。落断前先核辞义再落断：逐字查所引之辞原文与自带断辞，先定其本身主吉、主凶还是参半，再写自己的断语。严禁引吉辞反作凶断或反作「平安无事」式反面结论、引凶辞反作顺遂；体用/象数与辞义方向冲突时，两路并列写明并说明取舍，不许暗中翻转辞义迁就结论。核不出辞义原文者不许引该辞作断（细则见 `references/chinese-liuyao-meihua.md` 梅花篇「爻辞取象核对」）。
- **（e）事实优先序**：占题给定的**事实优先于类象自由发挥**——时令、外应、所占对象的具体处境（已知身份、现状、已发生之事）是取象的约束范围，不是可有可无的背景。类象多读时取与事实相合者；类象与事实正面冲突时以事实为准改象或弃象，不许以象压事实、虚构与事实相反的场景。此即《梅花易数》「推数又须明理」之序在全体系的推广：明理先对实情，再及联想。断语收束前须**逐项对回占题事实**（时令对过、外应对过、对象处境对过），对不上的断语删除后才许交付（细则见 `references/chinese-liuyao-meihua.md` 梅花篇「事实优先序」）。
- **（f）应验对象定位复核**：**方向对、对象错，与方向读反同为未完成作断。** 收束前逐条关键断语（凶、吉、病、破耗、成败各至少核其主断语）做三项核对：① **承受对象**——这条断语断的是谁/何物，写明到具体对象（占问者本人、其某位亲属、对方、或畜物、器物、场所等非人对象）；② **应验对象**——按本体系的指代链（六爻六亲与爻位、梅花体用与外应物象、八字十神与宫位、塔罗/占星的宫位与指代）推，这条断语的应验将落在谁/何物身上，同样写明；③ **同一性**——承受对象与应验对象必须为同一对象才许保留该断语。**非人对象是常备候选，不许默认回收到人身上**：外应、象中出现的畜物、器物、场所本身即可能就是应验对象（如象主牲畜见害即断牲畜，不许转断其主人家遭丧亡）；反之，断在人身上的病位、灾伤，也须能指回指代链落于此人，不许把亲属之灾回收到占问者本人、或把本人之病错落他人。指代链有二解者，并列写明二解与取舍依据；核不清同一性者，删该断语或明写「对象定位存疑」并降置信，不许含糊过关。此条与（e）分工：（e）核断语与占题事实是否相合，本条核断语内部「断者」与「应者」是否为同一对象（细则见 `references/chinese-liuyao-meihua.md` 六爻篇「用神对象定位复核」与梅花篇「应验对象定位核对」、两篇精通检查表各一条）。**六爻病占／行人类应验对象复述（检查动作，非新格式段落）**：六爻病占与行人类在作断末尾另强制一步复述——在 reasoning 与既有对象对齐检查内，把每条主断语的主语逐条复述并对回所问对象（本人／父／母／弟等逐名对回，不许以「家人」「对方」一类泛称含糊带过）；复述对不上所问对象、或主语指不回其六亲指代链者，即按对象错位改断或删去。此步只作复述检查，不在五段输出中另立段落、不新增任何强制输出段落（细则见 `references/chinese-liuyao-meihua.md`「对象对齐表」病占／行人复述专条）。
- **（g）具体断语密度（梅花及一切取象类）**：梅花及一切取象类占法（外应、象数、类象取断者皆属之）的断语，在合（c）事件级之外，还必须达到**事象级密度**——每条主断语至少落到下列四项中的**一项**并写实：① **人物**（何人、何身份、何关系之人出现、参与或受应）；② **物品**（何物、何类器物/食物/牲畜等具体物象出现、得失或见害）；③ **数量**（几人、几件、几许财物等可数的量）；④ **应期数字**（几日、几月、何日何时等带数字的应期）。四项俱无、仅以「大吉」「小吉」「先惊后安」「有客来」「事可成」一类**泛吉凶收束**者，视为未完成作断，必须回体用生克、外应物象与占题事实继续推到事象级才许交付；象数与事实只能支持到吉凶层级、四项确实一项也落不下者，须明写「此象只能定到吉凶层级，事象级推不出，依据不足」并降置信，不许用泛吉凶冒充事象级断语。此条与（c）分工：（c）定断语须落到事件（具体人/事/物），本条定取象类断语的密度下限（人物/物品/数量/应期数字至少居其一），两条同时执行、不互相替代；应期数字落断时仍须合（a）应期定点（单位与推得路径一并写明）。
- **（h）应期三步（跨体系，凡断语含应期者必经）**：（a）定「应期须写明单位与依据」之要求，本条定其执行程序——凡断语含应期者，落定值前必须先走完下列三步，缺一步视为应期未推完，不许交付：① **定尺度**——依所问事项的时间属性（近病近事、仕途升迁、一生运程之别）与盘面结构（卦之动静与空墓伏藏、命局之运年层级等时间结构），先定应期单位（年 / 月 / 日 / 时，四选其一），并**写明定此尺度的依据**（所问何事、盘面何结构支持此尺度）；② **列三路候选**——三路各给出候选值，逐路写明：六爻为**冲实、填实、逢值**（八字为**运年触发、合冲引动、值年值月**，其余体系按其自有应期法类推三路，如占星行运成相、塔罗牌阵时间位之属），一路无候选者明写「此路无候选，理由为……」，不许略过；③ **取一舍二**——取与**终局方向自洽**的一路为定值（该路所主之成败、轻重与终局断语同向同级），其余两路逐路**写明舍弃理由**（尺度不合、与终局方向相悖、候选值已被先行条件否决等，须落到具体理由，不许只写「不取」）。**明文禁止**：其一，**尺度未定就直报具体日期/数字**——未写明单位与定尺度依据而直接给出某日、某月、若干日月之数者，该应期断语不成立，须回本条重走；其二，**三路只报一路而不及其余**——只写定值一路、对其余两路不列候选、不写舍弃理由者，视为应期未推完。本条与（a）分工：（a）定应期断语的合格标准（单位＋依据），本条定得出定值的程序（三步），两条同时执行、不互相替代；事件型占断（六爻为主，含梅花／卜筮类事件断）走完三步后的定值落法从（a）双层表达：三路候选先定窗口边界、再在窗口内取主坐标，三步程序与取一舍二留痕不变；六爻与八字的本地化表述见 `references/chinese-liuyao-meihua.md`「应期三步（六爻本地化）」与 `references/chinese-bazi-ziwei.md`「应期三步（八字本地化）」。
- **（i）两段式终局检查（跨体系，凡所问事项天然有时间纵深者必经）**：所问事项本身有先后两段进程者，终局不得由一段定——断语必须分**「近段」与「远段」两段各给结论**，每段各写方向与轻重，并各给其应期（应期仍合（a）定点与（h）三步）。**适用范围**：凡所问事项天然有时间纵深者皆属之——疾病痊愈进程（目下病势与后段转归）、诉讼（近段审理／僵持与远段结案）、行期（近段动身与否与远段到达）、寻物（近段有无踪迹与远段得失）、营生开张（近段开立顺逆与远段存续盈亏）、雨晴过程（近时雨晴与后段转晴转雨）等，余类按「其进程是否天然分先后两段」类推认定。**两段分界**：以占问的时间尺度与盘面结构定分界点（如病以当前病程与下一转折期为界、讼以本审与结案为界），写明分界所据，不许两段混作一段写。**明文禁止：只报一段定终局**——只断近段即收束为终局（如只断目下可愈即断全愈、只断本年无妨即断终身无厄），或只断远段而略去近段者，均视为终局未断完，须回本条补齐另一段再交付。**只支持一段时的处理**：盘面只支持一段有据、另一段确实无据可断者，须**明言另一段无据不报的理由**（指明盘面何处无据：如远段转归之字未动未现、无应期之路可推之类），写明后才许以单段交付，不许默默略过装作已断全程。所问为单点事项、无时间纵深者（如只问此刻在否、单次成败而无后段进程），本条不适用，断语中明写「此问无近远两段，不适用两段式」即可，不许为凑两段硬拆。**远段触发指认（收紧，必经）**：远段结论不是近段结论的自然延伸——每条远段结论必须在断语中**指认其盘面触发**：写明是哪一动爻／变爻、或哪一日月冲合指向远段时点（格式如「远段之转出自第 X 爻动而化……，应在……之期」「远段之危出自日辰冲……、月建合……，指向……时点」），触发、远段时点与远段方向三者能对上，才许落远段断语。**无触发可指认者，不得报远段**：须在断语中明言「**一段终局，远段无据不报**」，并连同盘面何处无据的理由一并写明（承上「只支持一段时的处理」），以一段终局交付，不许默默以两段式交付。**明文禁止为凑两段虚构转折**——盘面无指向远段的动变冲合而硬造「先好后坏／先危后安」式转折者，该远段断语不成立，删去后按一段终局交付；亦禁止以泛泛套语充远段——「后有反复」「后来又有变数」「远段转愈／转危」一类无触发、无时点、无具体事象的句子不算远段结论，出现即按无远段处理并明言「一段终局，远段无据不报」。近段结论不受本款限制，仍按本条前文给方向、轻重与应期。本条与（h）分工：（h）管每段应期如何推得，本条管终局断语的结构——有纵深者必须近、远两段俱全；六爻病占的原神存续判别见 `references/chinese-liuyao-meihua.md`「病占原神有根／源绝成文判别」。
- **（j）分段结论逐段核对（跨体系，凡断语含分段结构者必经）**：凡断语含分段结构者——两段式近段／远段、大运逐段、终局段皆属之——**每一段的方向结论必须独立核对，不许一段推全程**。逐段执行三件事：① **独立指认该段依据**——每一段的方向（吉／凶／平、成／败、升／降）必须在该段断语中指认**该段自己的**盘面依据：六爻指认该段所据的动化方向（化进／化退／回头生克何者）、八字指认该段所据的触发运年（哪步大运、哪年流年）、以及两体系通用的冲合指向（何爻／何字冲合何爻／何字、指向何时点／何运段）；指认不出该段依据者，该段不许落方向结论。② **按所在体系的定性优先序核对**——该段方向须过所在体系既有的定性优先序再定：六爻过「动化定性裁决表」（动化方向定性优先、静态表象只调量级、反转只出两路），八字过「运断主线先行＋转折运段方向判定＋双向证据对决」（方向出自作用表与对决，不出自运名印象），其余体系按其自有定性序类推；**禁止由近段（首段）结论外推远段／后段，禁止由整体格局印象外推任何一段**——近段之吉不自动带出远段之吉，格局之贵不自动带出终局之贵，每段方向只认每段自己的依据与优先序结论。③ **反向段必须写明翻转触发**——某一段与首段（或前段总体）方向相反时，必须在**该段断语中**写明翻转触发：是何爻动化、何运何年引动、何冲何合改变了何字／何爻的存废状态（格式如「远段翻凶，翻转触发为第 X 爻动化回头克……」「终局段翻贵，翻转触发为该运冲去原局病字……」），触发须能改变该段所据之字／爻的状态，只写十神到位、运名五行或「运势转折」一类表面理由者不算触发。**无触发可指认者，该段只许二选一表述**：「**延续首段方向**」（方向与首段同、只许调整轻重与应期）或「**无据不报**」（该段方向不明写无据、不断方向）；不许无触发而自立与首段相反的方向。本条与（i）分工：（i）管分段结构是否俱全（有纵深者近、远两段俱全、远段须有触发才许报），本条管**每一段方向如何定**（逐段指认依据、逐段过优先序、反向逐段写触发），两条同时执行、不互相替代；八字运程分段的本地化衔接见 `references/chinese-bazi-ziwei.md`「运程分段断语格式与等级上限规则」。六爻作断时，reasoning 须按 `references/chinese-liuyao-meihua.md`「动化定性裁决表」执行留痕，含「动化方向」与「反转条件」两行定式核对结论，缺此两行者视为未执行裁决表。
- **（k）应期尺度通则（跨体系，凡断语含应期者必经）**：**应期单位必须与所问事项的时间跨度匹配。** 给出任何应期断语之前，先定本题的应验跨度——**日／月／年三档，必居其一**——并在 reasoning 中写明所定档位（如「本题应验跨度定为年档，依据为……」），未写明档位者视为应期未定点，不许交付。**月／年档（下列问题不得径直落到某一日）**：终局类（生死、成败终局、仕途终点）、年运类、回溯定位类（问何年何月发生）、远期应验类问题，应期以**月／年**为单位给出，顺序**先定年、再定月**；年未定准不许先报月，月／年档内不许径直落到某一日。**日档仅限下列情形**：① 占近事——问近日成行／消息／病愈日期且问题本身以日为尺度者；② 当日或数日内的应验；③ 卦／盘信息本身只支持日级定位的情形。使用日单位时，须在 reasoning 中**写明为何本题是日尺度**（属上列何种情形、问题本身或盘面何处支持日级定位），写不出理由者不得用日单位，须回月／年档重定。**本条与既有应期条文的分工**：（h）应期三步管「从盘面何处取应期」（定尺度、列三路候选、取一舍二的取数程序），本条管「应期用什么单位表达」（单位须与所问时间跨度匹配）；执行顺序为**先按本条定单位，再走（h）三步取数**，（a）应期定点（单位＋依据一并写明）照旧同时执行、三条不互相替代。
- **（l）事件型终局单判（六爻事件型占问，判定内容，非格式段落）**：六爻问一事之成败／愈否／归否等事件型占问，最终方向只许在单一终局中二选一落定——summary 与 direction（以 positive／negative 记法落盘者同此）必须同为该单一终局（成／不成、愈／不愈、归／不归所对应的一边），**禁止 mixed**，亦禁止以两可、先成后败式并陈充当终局方向。近段／远段两段式判断（通则（i）（j））仍照旧执行，但两段只许写入 reasoning 作过程依据，收束时必须按终局段的盘面依据（承（j）逐段核对与「终局反转信号扫查」门槛）合成一个终局方向，不许把两段方向原样并列为最终方向。mixed 只保留给命造类（八字／紫微）的分段格局表述；本条不改八字／紫微任何既有规则，亦不改 horary 等其他体系的既有规则条文，只收六爻事件型占问的终局落法。


## 解卦输出格式（固定五段）
1. **原始结果**：卦象逐爻/牌面逐张/盘面完整呈现（工具原始输出或盘面表），不许只给结论不给盘。
2. **所用之法**：一句话（体系+关键约定）。
3. **逐项解读**：每条断语后标依据（规则出处或典籍成例编号，如「用神午火空伏，出空应期——《增删卜易》用神章，例 LY-01」）；回扣不上的写「推测：」前缀或删去。
4. **倾向判断**：方向 + 条件 + 应期/关键变量；应期须合「作断通则（a）应期定点」（写明单位与依据）与「（k）应期尺度通则」（先定本题应验跨度为日／月／年何档并在 reasoning 中写明档位；终局／年运／回溯定位／远期应验以月／年为单位、先年后月、不得径直落到某一日；用日单位者已写明本题为日尺度的理由）与「（h）应期三步」（先定单位再走三步取数：列三路候选、取一舍二并写明舍弃理由；尺度未定不许直报日期/数字），等级须合「（b）等级校准」（降格/升格写明依据），断语须合「（c）事件级断语」（落到具体人/事/物与程度），引爻辞/卦辞者须合「（d）爻辞取象核对」（断语方向与原辞吉凶一致），全部断语须合「（e）事实优先序」（收束前逐项对回占题事实），且须合「（f）应验对象定位复核」（逐条关键断语的承受对象与应验对象同一，含畜物、器物等非人对象），梅花及取象类断语另须合「（g）具体断语密度」（人物/物品/数量/应期数字至少居其一，不以泛吉凶收束），所问事项天然有时间纵深者另须合「（i）两段式终局检查」（近段、远段各给结论含各自应期，不以一段定终局；远段已指认盘面触发——哪一动爻／变爻／日月冲合指向远段时点，无触发者已明言「一段终局，远段无据不报」，未以虚构转折或泛泛「后有反复」一类套语充远段），含分段结构者另须合「（j）分段结论逐段核对」（每段已独立指认该段依据并过所在体系定性优先序，未由近段结论或整体格局印象外推；与首段反向之段已写明翻转触发，无触发者已表述为延续首段方向或无据不报）；六爻另须合（l）事件型终局单判（终局单一方向、不以 mixed 收束）与（a）（h）六爻应期双层表达（应期以窗口＋窗口内单一主坐标进倾向判断、备选只入 reasoning），六爻病占／行人类另须已完成（f）应验对象复述；多法收敛或分歧按自决节呈现；带不确定性说明，不作绝对断言。
5. **归档行**：按下节格式给出本次记录摘要。

## 归档格式（每次占卜必留）
```
日期时间（公历+干支）｜求测者（可匿名）｜原问（原文）｜占法与约定（一句话）｜原始结果（卦/牌/盘要点）｜断语要点｜应验回填（日后补，未验留空）
```
存入当次对话上下文即可；用户要求落盘时写入原工作区知识库的 readings 目录（外部位置，见 `VALIDATION.md` 外部资产清单第 8 项；自行建目录）。

## 盲测与迭代（维护时）
- 调规则只看大师验证集（外部资产，见 `VALIDATION.md` 外部资产清单第 6 项）的 dev（校准集）与种子题卡的校准题；**test 留出集答案（验证集 holdout 目录）封存，只在阶段验收开封跑一次**，任何情况下不许把留出集答案给盲测方、不许据其调规则。
- 每轮迭代记入原工作区 benchmark 的 iterations.md（外部资产，见 `VALIDATION.md` 外部资产清单第 7 项）：分数、归因、改了哪条规则（须回扣典籍原文）、复测结果；防过拟合——不为单个案例改歪规则。
- 内部版数据集为全量：`redistributable` 只影响未来公开发布的导出过滤，与内部收录/划分/评分无关；发布动作须用户点头。
- evaluate.py 示例只是脚本自检夹具，**不是**盲测成绩，不许当成绩汇报。

## 资料处理规矩
扫描件/古籍中 OCR 读不出的内容（盘图、speculum、题头、手写字）改用多模态视觉读图转录：标注 transcription=visual 并给置信度；关键数据（出生时刻、干支、度数）须与上下文规则交叉验证；不许因 OCR 失败放弃、更不许臆补。

## 纪律与边界
- 没起卦不说卦、没排盘不说盘：任何「结果」必须来自工具实际运行或历算库实际计算，并保留原始输出备查。
- 重大决定（医疗、法律、投资、安全）只作参考输入，明确提醒叠加现实专业判断；不下「改命/破解」类断语；不替求测者占第三人隐私之事。
- 梅花托名、滴天髓作者未决、紫微史源等问题被问及时照实说明，不包装。
- 本 skill 与知识库冲突时，以用户最新定调（总目标节）为准；与调研报告的核实结论冲突时，以调研报告为准并回改知识库。
