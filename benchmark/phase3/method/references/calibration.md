## 二、计算层实测（2026-10-29 首轮）

### 2.1 铜钱起卦概率分布（cast_iching.py）
- 方法：调用 toss_line() 48,000 次统计和值分布。
- 结果：6（老阴）=0.126、7（少阳）=0.374、8（少阴）=0.374、9（老阳）=0.125。
- 理论值（铜钱法）：0.125 / 0.375 / 0.375 / 0.125。**一致**（偏差 ≤0.001）。
- 注意：此为铜钱概率；蓍草法概率不同（老阳概率约为老阴 3 倍，朱熹复原说）。本库默认铜钱法并在输出中声明；专业场合需蓍草概率时改用蓍草实现（rluu/iching 为参照），不得混用不言明。

## 五、列面—证据双闸收束复核（R59 干预 R59-REV1，跨体系收束机制）

R59 预注册干预，自 R60 轮起算效力；判读口径见 runs/round59/PREREG.md §3 与本节集成记录。

### 列面—证据双闸收束复核（R59 干预，跨体系通则；编号 R59-REV1）

**（一）适用面**：全体例通用。凡作断交付前，不分体系（六爻、梅花、八字、紫微、六壬、奇门、测字、梦占、塔罗、占星及其他取象类皆同）、不分问题门类、不分案例来源，一律执行本条。本条不指定任何主法，不改变选法自决，不因样本来源、段别或体系分层而增减执行项；分段只是诊断口径，不是执行口径。

**（二）第一闸·列面（交付前，先列面后收束）**：终局断语写定之前，先在 reasoning 中列一张「已载面表」，把**题面（案例卡／占题）已经载明**的面逐面列清。列面只许以题面已载内容为据，不许以盘面联想新增题面没有的面。每面一行，逐行处置，三选一并写明：
1. **已断**：该面已进入断语，注明对应哪条断语；
2. **有面无据不报**：该面在题面已载，但盘面无可指认的判断路径，注明无据之处（何字／何爻／何宫无据），不许默默略过装作已覆盖；
3. **与所问无关不报**：注明与所问无关的理由。

列面至少逐项扫过下列通用面类（有则列、无则在表末一句话总括「余面题面未载」即可，不许为凑表逐面虚列）：
1. 主问面（所问之事本身的成败／吉凶与主导面）；
2. 题面已载的事件面（已发生或题面明示将发生之事件、过程形态、事发形态）；
3. 题面已载的关系面（亲属、配偶、婚育、合作方、对方等题面出现过的人际指代面）；
4. 题面已载的对象面（财物、器物、场所、畜物、天气／环境等题面出现过的非人对象面）；
5. 应期与形态面（题面已给的时间线索、数量、方位、名号、文字／数字锚点所自带的面）。

其中第 5 项另设一核：题面锚点（数字、文字、名号、方位、卦名等）被取直读使用者，必须同时把其**反转面／转应面**（如数字之倒读与合读、文字之反义与转指、锚点所指对象之转移）列入已载面表一行，处置为「取直读、舍转应，理由为……」或「取转应，理由为……」；只取直读而不列转应面者，视为列面未完成。

**（三）第二闸·断项证据（每条具体子断过闸）**：第一闸完成后，对草稿中每条**具体子断**（落到具体人／事／物／数量／形态／时点的断项；主断方向本身亦在其内）逐条过闸。每条须同时指认两项才许以确定断语交付：
1. **指代链**：该断项经本体系指代链落在何对象（承通则（f），如六亲与爻位、十神与宫位、宫位与指代之属），指回题面已载面表中的哪一行；
2. **盘面触发**：一条可指认的盘面依据（动变、冲合、生克旺衰状态、星曜宫位结构、牌位、辞义之属，须写明具体何爻／何字／何宫／何辞，不许只写体系套语）。

两项俱全者保留；只有其一者（多为只有类象联想、或只有指代而无触发）降格为「推测：」前缀并降置信，或删去，二选一并在留痕中注明；两项俱无者直接删去，不许以「宁可多断一条」为由保留。**未载面禁断**：凡指代链指不回已载面表任何一行的子断，一律按两项俱无处理——本闸宁可删未载之断，不许以新增子断去「覆盖」题面没有的面。

**（四）主核保护**：双闸不得稀释主断。每例交付的断语仍以主问面的主断为核（承胜例形态：主断单核命中且自带应期坐标）；次面断语只许在主断写定之后按闸保留，不得与主断并列争夺终局方向，不得因次面子断之增减改变主断方向与等级（方向与等级仍只按通则（l）／（b）及各体系定性优先序定）。

**（五）留痕要求（缺留痕视为未执行）**：reasoning 中必须留下两张表的痕迹——① 已载面表（逐面一行＋三选一处置；锚点转应面一行不得缺，题面无锚点者明写「本题面无文字／数字锚点，转应核不适用」）；② 断项过闸表（逐条子断一行：断项→指代链所指已载面行号→盘面触发→保留／降格／删去）。两表只入 reasoning 与既有检查留痕，不新设输出段落，不改变五段输出格式；交付文本中只呈现过闸后保留的断语与「有面无据不报」类明言，不呈现被删断项。

**（六）与现行条文的关系（并列登记，不覆盖）**：
1. 与通则（c）事件级断语、（g）具体断语密度**并列且有张力**：（c）（g）管「断语须落到事件级／事象级、不许空泛收束」，本条第二闸管「落下去的具体断项须有据、无据者降删」；执行序为先按（c）（g）推到事件级、再按本条过闸筛选。（c）（g）的密度要求不构成对无据子断的豁免，本条的删减权也不构成回到空泛吉凶的许可——过闸后某面只剩吉凶层级者，按（c）（g）既有口径明写「事件级推不出，依据不足」并降置信。
2. 与通则（f）应验对象定位复核**并列分工**：（f）核单条断语内部承受对象与应验对象是否同一；本条第一闸核「面」的覆盖（该断的面有没有列到），第二闸核断项的证据充分性。同一断项三条同时执行，不互相替代。
3. 与通则（b）等级校准**并列分工**：本条的「降格」指证据不足时的置信降格（加「推测：」或删去），不是（b）意义上的等级降格；等级仍按（b）以格局／用神强度同级定，写不出压制依据的等级降格仍禁止，本条不为保守降格提供新借口。
4. 与通则（a）（h）（k）应期诸条**并列分工**：应期／事发形态面列入已载面表，只解决「该面有没有被看到」；应期数值如何推得仍只按（a）（h）（k）三步与双层表达，本条不新增任何应期取数法，不许借列面之名多报一个应期坐标。
5. 与通则（i）（j）分段诸条**并列**：远段／分段断语同样逐条过第二闸；本条不改变（i）（j）关于触发与逐段核对的既有要求，过闸表中的「盘面触发」与（i）（j）的触发指认可同一条兼记，不重复造表。

## 七、主断方向双路对决前置裁决（R78 干预 R78-REV1，跨体系方向裁决机制）

（集成登记：提案 runs/round78/diagnosis/REVISION-PROPOSAL-r78.md；自集成之次轮起算效力，照 R59／R61 先例。判读口径见提案 §3，本节不另改写。）

**R78-REV1-1（时点与适用面）**
本裁决在每例作断起手执行：先于任何具体子断、应期与等级的写出，先于交付前一切既有检查。全体例通用，不分体系、不分问题门类、不分案例来源；不指定主法，不改变选法自决。本条是方向的**形成**程序，不是交付前复核程序；第五、六节失效存档条文不因本条复活。

**R78-REV1-2（双路成形）**
就主问面的终局方向，在 reasoning 中先写一张「方向对决表」，正、反两路各一行，每行两栏：
1. **定性栏**：该方向在所在体系定性优先序顶层的依据链，逐条具体指认（何爻之动化、何字之存废、何宫之格局、何课格之主向），至少一条；该路确无定性依据者明写「定性栏空」。
2. **量级栏**：旺衰强弱、数量多寡、静态表象、类象印象之属，只登记，不计入裁决。
只列一路、或两路共用同一条定性依据而未写明其如何分别支持两路者，对决表视为未完成。

**R78-REV1-3（对决裁决）**
两路只按定性栏裁决，序如下：
1. 一路定性栏非空、另一路定性栏空（只有量级栏）者，取定性栏非空一路；
2. 两路定性栏均非空而冲突者，按所在体系既有定性优先序逐项对位，逐项写明哪一位阶、哪一条依据压过对方哪一条，取胜出位阶所属一路；
3. 两路定性同级、优先序对位不能分胜负者，依次按次级序裁决：先比应验对象指代链完整度（承通则（f）），再比与占题事实的相合度（承通则（e））；次级序仍不分者，取初判方向，置信降一档，表末登记「对决平局」。
**禁止以量级栏单独定方向**：旺相即吉、休囚即凶、表象繁盛即成、表象衰败即败一类只凭量级／表象的方向取法，不成立，出现即回本条重裁。

**R78-REV1-4（方向锁定与生成约束）**
对决落定之方向即锁定方向，构成通则（l）事件型终局单判的输入。此后具体子断、应期、等级只许在锁定方向内推衍（等级仍按通则（b）同级定，应期仍按通则（a）（h）（k）推得，本条不新设取数法与等级法）。推衍中遇到与锁定方向相反的盘面材料，只许在对决表下回记一行「反向材料：……，已于对决第 X 项处置」，不许据此另立第二方向、不许在交付文本中并陈两向、不许以子断条数反压主断。

**R78-REV1-5（与现行条文的关系，并列登记）**
1. 与通则（j）分段逐段核对**分工**：（j）管分段结构中每一段方向如何定，本条管主问面单一终局方向在起手处如何形成；分段各段方向仍逐段过（j），终局合成时以本条对决结果为收束输入，两条同时执行。
2. 与通则（l）**衔接**：本条对决落定的方向即（l）所定单一终局的方向来源；（l）的禁止 mixed 与两段合成规则不变。
3. 与通则（e）（f）**分工**：（e）（f）是本条次级裁决序的判据来源，本条不改变其既有执行要求。
4. 本条不处置应期坐标（TIM）、不断项粒度（CLAIM）、不查面覆盖（OMIT）：三者维持现行条文与口径，本条执行不构成对三者的豁免或替代。

**R78-REV1-6（留痕）**
reasoning 中须留方向对决表（正路定性栏／量级栏、反路定性栏／量级栏、裁决所经项次、锁定方向、平局登记如有）与反向材料回记行（无反向材料者明写「无反向材料」）。缺对决表视为未执行本条；留痕只入 reasoning，不新设输出段落，不改变五段输出格式。

## 八、做功主线与功量核算核（R80 干预 R80-REV1，跨体系量级核算机制）

（集成登记：提案 runs/round80/revision/PROPOSAL-R80-REV1.md；自集成之次轮起算效力，照 R59／R61／R78 先例。判读口径见提案 §五，本节不另改写。）

**R80-REV1-1（触发面，窄面限定）**
凡断语含量级类断项者，该断项写定之前执行本核。量级类断项三类：① 等级类——富贵贫贱、成事规模、病势轻重、得失程度等与格局／用神强度同级的等级断语（承通则（b））；② 数量／功量类——财物数量、人数、成事分量等可数之量；③ 分配类——二人或多方之间分得、分任、主副承担、谁得谁失之断项。不含量级类断项的断语不执行本核。本核只核算「量」的估算过程：不形成方向（方向归第七节对决与通则（l））、不推应期坐标（应期归通则（a）（h）（k））、不查面覆盖、不对断项作粒度降档。

**R80-REV1-2（做功线清单）**
对每一量级类断项，在 reasoning 中逐线列「功量清单」，每行四栏：作用源（具体何字／何爻／何宫／何星曜结构）、作用对象（该断项所指对象／用神）、作用向（助成／压制）、状态（旺衰与发动、受制状态）。只列可指认的盘面作用线（生克、冲合、刑害、会合之属）；类象联想、量级印象与体系套语不入清单、不计权。

**R80-REV1-3（主线认定与取线纪律）**
清单列毕，指认做功主线一行：直接作用于作用对象、且状态居首（发动／旺相／得地，逐项写明所据）的作用线为主线。量级断语的轻重取向须与主线作用向同向。以次线定量而与主线取向相反者，须写明主线让位依据（主线受制、被合去、空亡、伏藏等可指认状态，逐项指认）；写不出让位依据者，该量级断项不成立，回主线作用向重估。

**R80-REV1-4（合计定带与估低防线）**
按清单将助成线与压制线分列合计（计数＋状态强弱定性），先定等级带（与通则（b）强度同级），再在带内写量级断语。断语出带者，须按（b）写明压制／提格依据并逐项对回清单行号；写不出者回带内取值。估低防线：助成线 ≥2 条、压制线 0 条且无主线让位依据者，量级断语不得低于等级带中位——无压制而往轻里估，视为未核算，须回带内中位以上重估。

**R80-REV1-5（分配对读）**
分配类断项逐方各列其做功线与受力状态（并入同一清单、逐方分行），分配方向（谁多谁少、谁主谁副、谁得谁失）须与逐方相对强弱同向。写定后反读一遍：逐方核「谁对谁做功、谁承受其果」，断语主客与清单主客不一致者改断。本条与通则（f）分工：（f）核单条断语承受对象与应验对象的同一性，本条核多方之间量之分配方向。

**R80-REV1-6（与现行条文的关系，并列登记）**
1. 与通则（b）**衔接**：（b）定「等级须与强度同级、降格／升格须写明依据」之标准，本条定得出等级的操作程序（清单—主线—定带—对号），两条同时执行，本条不改（b）标准本身。
2. 与第五节（失效存档）**分工**：第五节于交付前查断项证据有无与面覆盖，处置为降格／删去；本条于写定前核算量级估算过程，处置为回带重估。本条不使第五节复活。
3. 与第六节（失效存档）**分工**：第六节对应期主坐标复推与断项粒度降档，本条不碰应期、不降粒度。本条不使第六节复活。
4. 与第七节**衔接**：第七节于起手定方向并锁定，本条于其后核算量；清单所列作用线与第七节定性栏可同一材料兼记，但用途分列——方向裁决不计入功量合计，功量合计不改锁定方向。本条执行中发现方向疑点，只许在 reasoning 登记「方向疑点、本核不处置」，不许借本核翻转方向。

**R80-REV1-7（留痕与缺痕处置）**
reasoning 中须留功量清单表（逐线四栏＋主线认定行＋定带行；含分配类断项者另加逐方对读行）。无量级类断项者明写「无量级类断项、R80-REV1 不适用」。缺留痕视为未执行本核；留痕只入 reasoning，不新设输出段落、不改五段格式。
