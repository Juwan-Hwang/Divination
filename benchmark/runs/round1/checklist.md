# 每轮执行清单（模板，各轮复制为 runs/roundN/checklist.md 后逐项勾）

## 开跑前
- [ ] 预注册写入 iterations.md 并复制到本轮 preregistration.md（假设、样本范围、评分口径冻结）
- [ ] 知识库/skill 版本快照或哈希清单冻结（kb-snapshot/）
- [ ] 五角齐备且互不兼任（数据/盲测/评审/修订/主持分别指派）

## 执行中（证据保全：只增不删，纠错只加 errata）
- [ ] 每个 agent 的任务原文存入 prompts/（发前或发后即存）
- [ ] 盲测原始输出逐例保存（predictions/），输入文件与发给盲测方的材料留档（inputs/）
- [ ] 评审原始打分表与点评保存（judge/），双评审一致性记录；分歧例仲裁记录存 arbitration/
- [ ] 修订角的规则改动以 diff 形式存 revision/，只依据聚合分数与差距清单
- [ ] test 金标开封（如发生）留日志（时间、执行者=评审角、事由）

## 收尾
- [ ] REPORT.md 落盘：评审分数与主持方诊断分开呈现；分数带 n；n<5 分项标注样本不足；著名/非著名分开；阴性结果照实报
- [ ] iterations.md 追加本轮结果行与分数轨迹
- [ ] 对本轮目录生成 SHA-256 清单存入轮目录（EVIDENCE.sha256）
- [ ] 检查停止标准：未达 → 立刻预注册下一轮并开跑；达标/平台期 → 按 PROTOCOL 走留出集验收或出总报告
