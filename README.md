市面上的 AI 算命，大多是背几句口诀，再顺着你的话往好听里说。

严肃占卜不这样。我们把几十部大师原著逐本读完——六爻、六壬、八字、紫微、奇门、测字、梦占；徐乐吾、王虎应、段建业、许铨仁、蔡明宏……——提炼出 **1,400 多条断法**，写成一包 AI 能直接执行的 Skill。然后拿大师当年真实断过、结局已知的案例，蒙住答案让它考，考到和大师对得上为止。

## 三十秒装上

**Claude Code**

```bash
git clone https://github.com/Juwan-Hwang/Divination.git
cp -r Divination/skill ~/.claude/skills/divination
```

重开会话后直接问就行，比如：

> 帮我起一卦：这次的 offer 该不该接？

**Claude.ai / 其他支持 Skill 的 Agent**：把 `skill/` 文件夹打包成 zip 上传，或让 Agent 读取 `skill/SKILL.md`。

起卦抽牌只用 Python 标准库，不用装任何依赖：

```bash
python3 skill/tools/cast_iching.py "这次的 offer 该不该接"   # 铜钱起卦
python3 skill/tools/draw_tarot.py 3                          # 塔罗三张
```

八字、紫微、占星排盘需要的历算库（lunar-python、iztro、pyswisseph）为可选外部依赖，Skill 会在用到时说明。

## 它和别的 AI 算命有什么不同

| | 常见 AI 算命 | 严肃占卜 |
|---|---|---|
| 卦从哪来 | 模型自己「想」一个 | `secrets` 密码学随机，真起卦，原始结果完整给你看 |
| 盘从哪来 | 凭印象报干支 | 确定性历法计算，立春换年、节气换月、真太阳时校正 |
| 断语依据 | 口诀拼贴、心灵鸡汤 | 每条断语标出处：规则章节或大师成例编号；对不上的标「推测」 |
| 流派之争 | 甩给你选：「您想用哪一派？」 | 算者按情景自决，末尾一句话交代用了什么法 |
| 结论 | 模棱两可，或者包你满意 | 方向 + 条件 + 应期，冲突时摆出分歧并说明取舍 |
| 怎么证明靠谱 | 不证明 | 封存考题盲测，规则考前写死，阴性结果照实公布 |

一次完整的解卦固定五段：**原始结果 → 所用之法 → 逐项解读（每条带依据）→ 倾向判断（方向、条件、应期）→ 归档行**。没起卦不说卦，没排盘不说盘。

## 成绩单

它是这样练出来的：

- **96 轮**盲测迭代，**5,419** 个 AI 席位，**76.6 亿** token
- **1,361** 个有大师原断和真实结局的历史案例做考题
- 出题、答题、判卷、改卷、主持**五个角色互不兼任**，判卷双评审加仲裁
- 规则考前写死、考后不改；考题封存并记录 SHA-256，开考之前谁也没见过答案

**和大师原断对得上多少**（v1，41 例封存测试，首次开封）：

| 指标 | 结果 |
|---|---|
| 逐例一致性得分 | **71.1%** |
| 通过（≥ 4/6 分） | 27 / 41 |
| 两位评审一致率 | 92.7%（κ = 0.827） |
| 与校准集近三轮均值差距 | 2.9 个百分点，没有过拟合的迹象 |

我们还做了一件更难的事：不比「像不像大师」，直接比「谁更准」，用真实结局给大师和 Skill 一起打分。结论是**还没赢过大师**——在干净样本上，大师几乎全对，Skill 仍有明显差距（Phase 2 留出集低污染子集 4.06 vs 5.35，满分 6）。这个结果我们照实写在报告里，没有改口径去凑。

## 能算什么

你只需要说清楚要问什么，用哪种占法由 Skill 自己定，也可以几种法互相参照：

| 你想问 | 首选 | 互参 |
|---|---|---|
| 一件具体的事成不成、什么时候 | 六爻纳甲 | 大六壬（补细节：何人、何方、经何过程） |
| 当下就要拿主意 | 梅花易数 | 周易 |
| 没有具体事，想看方向 | 周易文本占 | 塔罗 |
| 一生格局、运势周期 | 八字 | 紫微斗数 |
| 什么时候做、往哪个方向做 | 奇门遁甲 | — |
| 关系、心理、处境 | 塔罗 | 周易 |
| 手边一个字、一个梦 | 测字、梦占 | 六爻、梅花 |
| 出生星盘、行运 | 西洋占星 | 八字（跨体系对照） |

它只会追问事实（问什么事、出生时间和地点），不会把流派选择题推给你。同一件事不重复起卦，按《周易·蒙》「初筮告，再三渎，渎则不告」的规矩。

## 边界

占卜在这里是文化传统，也是一种决策参考框架，不是科学预测工具。典籍成例有幸存者偏差；盲测达标证明的是「断法与大师一致」，不证明预测效力。

- 医疗、法律、投资、人身安全：只作参考，必须叠加现实的专业判断
- 不替你占第三人的隐私，不说「改命」「破解」这类话
- 托名《梅花易数》、Waite 牌义这类现代建构照常使用，但出处真伪如实标注，不包装成古籍
